# Stock Tracker

A simple Python project that tracks stock prices and calculates the investment value based on the number of shares owned.

## Features
- View available stock prices.
- Calculate total investment value.
- Handle stock selection through user input.

## Technologies Used
- Python
- Dictionaries
- User Input and Conditional Statements
- String Methods

## Purpose
Built as part of my Python programming internship to practice Python fundamentals and problem-solving skills.
